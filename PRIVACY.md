# UBookmark Privacy Policy

**Last updated:** August 5, 2026

UBookmark is a local Chrome bookmark manager. This policy explains how the extension handles information.

## Information UBookmark stores

UBookmark stores the following information locally in the user's Chrome extension storage:

- Bookmarks, folders, tags, and notes created or imported by the user.
- Theme preference.
- A random salt and PBKDF2 password hash used to protect access to the local vault. UBookmark does not store the plaintext password.

## Chrome bookmark import

When the user selects **Import Chrome bookmarks**, UBookmark reads only the Chrome bookmarks the user selects and copies them into the local UBookmark vault. UBookmark does not modify or delete the user's original Chrome bookmarks.

## Data sharing and collection

UBookmark does not collect, transmit, sell, rent, or share user data with the developer or third parties. UBookmark does not use analytics, advertising SDKs, trackers, or remote servers.

## Optional developer tip

The optional **Tip the developer** link opens Buy Me a Coffee in a new browser tab only after the user reviews an in-app disclosure and chooses to continue. Payments are processed independently by Buy Me a Coffee under its own terms and privacy practices. UBookmark does not receive or store payment information.

## Data retention and deletion

Data remains in the user's local Chrome extension storage until the user removes individual bookmarks or folders, uses the in-app vault reset, or uninstalls the extension. If the password is forgotten, it cannot be recovered; the user can reset the vault by confirming deletion in the extension.

## Security note

UBookmark uses a salted PBKDF2 password hash and does not store plaintext passwords. Chrome extension local storage is not a dedicated encrypted vault, so users should consider the security of their device and Chrome profile.
